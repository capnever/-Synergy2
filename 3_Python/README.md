# Кейс задача 3

<h2>Создание чат-бота для автосервиса CarZona72</h2>

<p>В рамках практической кейс-задачи разработан чат-бот для автосервиса <b>CarZona72</b>.</p>

<p>По условию задания необходимо создать простой чат-бот, который распознаёт ключевые слова и предоставляет соответствующие ответы, после чего протестировать и отладить программу и выполнить её развёртывание, например, в Telegram.</p>

<p>Разработка выполнена на языке <b>Python</b> с последующей интеграцией с <b>Telegram</b>.</p>

<h2>Задача</h2>

<p>Необходимо реализовать чат-бота, который сможет:</p>

<ul>
<li>отвечать на типовые вопросы клиента;</li>
<li>предоставлять информацию об автосервисе;</li>
<li>показывать перечень услуг;</li>
<li>проводить пользователя по сценарию записи;</li>
<li>обрабатывать дату и время записи;</li>
<li>работать с подбором запчастей;</li>
<li>при необходимости переключать клиента на оператора.</li>
</ul>

<p>Бот адаптирован под предметную область автосервиса CarZona72.</p>

<h2>Возможности программы</h2>

<h3>Главное меню</h3>

<p>Пользователь может перейти к следующим разделам:</p>

<ul>
<li>ТО и масла;</li>
<li>диагностика;</li>
<li>двигатель;</li>
<li>тормозная система;</li>
<li>подвеска;</li>
<li>коробка передач;</li>
<li>рулевое управление;</li>
<li>шиномонтаж;</li>
<li>охлаждение и радиаторы;</li>
<li>кондиционер;</li>
<li>выхлопная система;</li>
<li>информация об автосервисе;</li>
<li>запись на обслуживание;</li>
<li>подбор запчастей.</li>
</ul>

<h3>Запись на обслуживание</h3>

<p>Бот последовательно запрашивает:</p>

<ol>
<li>услугу;</li>
<li>дату;</li>
<li>время;</li>
<li>наличие запчастей.</li>
</ol>

<p>Для времени реализована проверка рабочего диапазона автосервиса:</p>

<p><b>10:00–20:00.</b></p>

<p>Поддерживаются различные форматы ввода времени, например:</p>

<pre>
14
14:30
14-30
14.30
</pre>

<h3>Работа с датами</h3>

<p>Бот умеет обрабатывать несколько вариантов ввода даты:</p>

<pre>
завтра
послезавтра
среда
в среду
25.08
25.08.2026
</pre>

<p>После обработки дата приводится к единому формату.</p>

<h3>Свободное описание услуги</h3>

<p>Если клиент выбирает пункт <b>«Другое»</b>, ему предлагается самостоятельно описать необходимую работу.</p>

<p>После получения текста бот сохраняет описание и предлагает подтвердить необходимость записи.</p>

<h3>Подбор запчастей</h3>

<p>Пользователь может выбрать вариант:</p>

<ul>
<li><b>Запчасти уже есть</b>;</li>
<li><b>Запчасти нужно подобрать</b>.</li>
</ul>

<p>При необходимости подбора бот последовательно запрашивает:</p>

<ol>
<li>VIN или номер кузова;</li>
<li>название требуемой запчасти;</li>
<li>подтверждение заявки.</li>
</ol>

<p>После подтверждения заявка передаётся оператору.</p>

<h3>Режим оператора</h3>

<p>Предусмотрен отдельный режим общения с оператором.</p>

<p>При подключении оператора автоматические ответы бота отключаются. После завершения общения можно вернуть автоматический режим.</p>

<h2>Команды навигации</h2>

<table>
<tr>
<th>Команда</th>
<th>Назначение</th>
</tr>
<tr>
<td>назад</td>
<td>Возврат на предыдущий этап диалога</td>
</tr>
<tr>
<td>начало</td>
<td>Возврат в главное меню</td>
</tr>
<tr>
<td>отмена</td>
<td>Отмена текущего сценария</td>
</tr>
<tr>
<td>выход</td>
<td>Завершение работы</td>
</tr>
</table>

<h2>Telegram-интерфейс</h2>

<p>После тестирования консольной версии бот был интегрирован с Telegram.</p>

<p>В Telegram используются <b>inline-кнопки</b>, благодаря которым пользователь может выбирать категории и действия без ручного ввода номеров.</p>

<p>Текстовый ввод сохраняется для данных, которые удобнее вводить вручную:</p>

<ul>
<li>VIN;</li>
<li>дата;</li>
<li>время;</li>
<li>свободное описание услуги;</li>
<li>название запчасти.</li>
</ul>

<h2>Установка</h2>

<h3>1. Установка зависимостей</h3>

<pre>
pip install -r requirements.txt
</pre>

<h3>2. Настройка Telegram-бота</h3>

<p>Для работы требуется токен Telegram-бота, полученный через <b>BotFather</b>.</p>

<p><b>Важно:</b> настоящий токен не должен публиковаться в открытом GitHub-репозитории.</p>

<h3>3. Запуск</h3>

<pre>
python telegram_bot.py
</pre>

<p>После запуска в терминале отображается сообщение:</p>

<pre>
CarZona72 Telegram Bot запущен...
</pre>

<h2>Принцип работы</h2>

<p>Основная логика бота реализована как последовательность состояний.</p>

<pre>
Главное меню
      ↓
Категория услуг
      ↓
Конкретная услуга
      ↓
Запись
      ↓
Дата
      ↓
Время
      ↓
Запчасти
      ↓
VIN / номер кузова
      ↓
Название запчасти
      ↓
Подтверждение
      ↓
Заявка оператору
</pre>

<p>При ошибочном вводе пользователь получает сообщение с подсказкой и может повторить ввод, не теряя текущее состояние диалога.</p>

<h2>Тестирование</h2>

<p>В ходе разработки было проведено ручное тестирование основных сценариев.</p>

<ul>
<li>проверка главного меню;</li>
<li>проверка всех основных категорий услуг;</li>
<li>проверка пункта «Другое»;</li>
<li>проверка записи на обслуживание;</li>
<li>проверка некорректных значений даты;</li>
<li>проверка некорректных значений времени;</li>
<li>проверка команды «назад» на разных этапах;</li>
<li>проверка подбора запчастей;</li>
<li>проверка VIN и подтверждения заявки;</li>
<li>проверка режима оператора;</li>
<li>проверка Telegram-кнопок.</li>
</ul>

<p>В процессе тестирования были исправлены ошибки обработки состояний, даты и времени, навигации, передачи меню в Telegram и работы callback-кнопок.</p>
